# Custom React Hooks Directory

Scheduled hooks for Phase 1 and beyond:
- `useGeolocation.ts`: High-accuracy browser GPS location and watch tracking.
- `usePollutionData.ts`: SWR / React-Query hooks for real-time sensor streams.
- `useMapViewport.ts`: Synchronization between URL params and geospatial camera state.
- `useIncidentFilter.ts`: Filter multi-criteria incident triage feeds.
