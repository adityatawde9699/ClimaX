# Frontend API Services Directory

Encapsulates typed API call wrappers talking to `/api/v1/*`:
- `authService.ts`: Session tokens, login, logout, profile.
- `sensorService.ts`: Real-time readings, nearest sensor queries.
- `reportService.ts`: Citizen incident reporting with media uploads.
- `incidentService.ts`: Authority dispatch, triage, resolution.
- `predictionService.ts`: 6h-72h forecast retrieval.
- `aiService.ts`: AI Copilot conversational sessions.
