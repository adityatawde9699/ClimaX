# Frontend Shared Components Catalog

- `ui/`: Fundamental atomic UI primitives (Buttons, Badges, Modals, Inputs, DataTables) compliant with ClimaX Design Tokens.
- `layout/`: Shell layouts for Command Center, Citizen Mobile Viewport, Researcher Console, and Navigation sidebars.
- `common/`: Reusable domain widgets (AQIGauge, InformationTierBadge, ConfidenceMeter, ThreatIndicator).
- `maps/`: Mapbox/Google Maps wrapper components, LayerControllers, PlumeOverlays, and HexbinRenderers.
- `feedback/`: Toast alerts, ErrorBoundaries, and OfflineBanner notices.
