# Route Group: (citizen)

Houses the citizen-facing mobile-first experience.

## Sub-routes (Scheduled for Phase 4):
- `/citizen` - Local environmental dashboard & nearby AQI
- `/citizen/map` - Interactive citizen pollution map
- `/citizen/report` - 1-tap photo/video incident report submission
- `/citizen/insights` - Hyper-local health advisories & personal exposure tracking
- `/citizen/assistant` - Citizen AI environmental assistant
- `/citizen/profile` - Submission history & notification preferences
