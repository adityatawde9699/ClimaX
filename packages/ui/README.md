# @climax/ui — Operational Design System

This package provides design tokens, visual primitives, and standardized operational contracts for ClimaX.

## Visual Design Principles

1. **Government Tech & Environmental Command**:
   - Palette inspired by high-stakes monitoring consoles (aviation, seismic, emergency response).
   - Base dark theme (`#0B0F17`) reduces eye strain during 24/7 monitoring room operation.
2. **Standardized Severity Visuals**:
   - Uses strict EPA/CPCB continuous AQI color scales (Green → Amber → Orange → Red → Purple → Maroon).
   - High-contrast pill badges distinguish between Observed, Inferred, Predicted, and Verified information.
3. **No Fluff**:
   - Zero decorative glassmorphism or distracting bouncy animations that degrade performance on field devices.
